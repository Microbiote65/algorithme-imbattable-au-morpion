# algorithme-imbattable-au-morpion
Jeu de Morpion (Tic-Tac-Toe) fluide et responsive, développé en HTML/CSS et JavaScript pur.  Grâce à l'algorithme Minimax, l'IA anticipe tous les coups possibles : elle est totalement imbattable. Impossible de gagner, vous pourrez au mieux obtenir un match nul !  Développé par @Microbiote65 .
